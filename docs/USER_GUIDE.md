# WealthLab 使用文档

WealthLab 是一个安卓自用实验 App，包含两个模块：双色球实验推荐和 A股量化研究。数据默认保存在手机本地，不需要注册账号，不接券商交易。

## 1. 首页

- `状态`：显示最近一次导入、更新、生成推荐或回测结果。
- `第 xxxx 期双色球`：显示最近生成的一组目标期推荐。
- `最近回测`：显示最近一次股票策略回测结果。
- `观察池`：显示已导入股票数和回测数。

## 2. 双色球数据更新

进入 `数据` 页，在 `双色球数据` 区域有三种方式：

- `服务端更新`：推荐方式。填写你部署的轻服务端地址，如 `http://192.168.1.8:8000`，App 会从服务端拉取尽可能多的历史开奖。
- `官网直连`：备用方式。手机网络直连中国福彩网，部分环境可能返回 HTTP 403。
- `导入CSV`：离线兜底，选择手机里的 CSV 文件。

轻服务端部署方式见 [server/README.md](../server/README.md)。

双色球 CSV 格式：

```csv
issue,date,r1,r2,r3,r4,r5,r6,blue
2024001,2024-01-02,1,6,12,18,24,30,8
```

## 3. 双色球推荐

进入 `双色球` 页：

1. 先确认 `数据分析` 卡片里有 30 期以上历史数据。
2. 在 `复式方案` 调整红球数和蓝球数，例如 `6+3`、`7+2`、`9+3`。
3. 点击 `生成推荐`，服务端会即时运行分析模型并返回结果。

新版推荐逻辑：

- 不再无数据随机兜底；少于 30 期会提示先更新数据。
- 每组推荐都显示目标期号和依据的最新开奖期号。
- 同一目标期、同一历史数据、同一复式方案下，重复点击会得到稳定结果。
- 推荐前会展示计算依据：全量频率、最近窗口加权、遗漏、样本量、目标期号、复式注数。
- 默认输出 `3` 组单式和 `1` 组复式。

### 可解释研究区

`双色球` 页现在还会展示：

- `模型参数`：可切换 `均衡`、`近期`、`基线` 三种模型，并调整最近窗口和预算注数。
- `历史回测`：看当前模型在最近历史样本上的平均最佳红球数、蓝球命中率和至少 3 红比例。
- `模型对比`：横向比较多个模型版本的回测表现。
- `推荐表现追踪`：保存你实际生成过的历史推荐，等对应期开奖后自动回看表现。
- `预算建议`：在预算注数内给出更合适的红蓝复式覆盖方案。
- `推荐理由`：每组号码会说明热号、遗漏号、形态和蓝球选择原因。
- `逐球解释`：每个号码都会显示总分、全量频率分、近期分、遗漏分、形态分，以及它被纳入推荐的具体原因。
- `号码榜单`：可在红球榜/蓝球榜之间切换，并按综合、近期、遗漏排序；点某个号码可以查看近 30/60/120 期轨迹、最近出现期号，以及它为什么入选或暂未入选。

复式注数计算：

- `6+1`：1 注。
- `6+3`：`C(6,6) * 3 = 3` 注。
- `7+2`：`C(7,6) * 2 = 14` 注。
- `9+3`：`C(9,6) * 3 = 252` 注。

## 4. A股量化

进入 `数据` 页，在 `A股日线数据` 区域填写：

- `股票代码`：例如 `000001`。
- `名称`：例如 `平安银行`。
- `CSV地址`：HTTP 更新时使用，支持 `{symbol}` 占位符。

日线 CSV 格式：

```csv
date,open,high,low,close,volume
2024-01-02,10.00,10.50,9.90,10.20,1000000
```

进入 `量化` 页，选择股票后点击 `运行回测`。当前内置策略包括均线交叉、RSI反转、MACD趋势和 20 日突破。

## 5. 备份与恢复

进入 `数据` 页，在 `备份与恢复` 区域：

- `导出`：保存本地数据为 JSON。
- `恢复`：从 JSON 文件恢复。

## 6. 注意事项

- 双色球推荐是统计实验和娱乐工具，不保证中奖。
- A股回测只用于研究，不构成投资建议。
- 如果手机端官网直连 403，请使用轻服务端更新。
- A股 HTTP 更新要求目标地址直接返回 CSV 文本。
