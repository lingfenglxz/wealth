# WealthLab 使用文档

WealthLab 是一个安卓自用彩票实验 App，当前包含福彩双色球和体彩足球彩票。数据默认保存在手机本地，不需要注册账号，不包含购彩、支付或下单功能。

## 1. 首页

- `状态`：显示最近一次导入、更新或生成推荐结果。
- `真实推荐结算`：统计已开奖的双色球复式推荐表现。
- `第 xxxx 期双色球`：显示最近生成的一组目标期推荐。
- `体彩世界杯`：显示已准备的足球赛事数量和下一场赛事。

## 2. 福彩：双色球

进入 `福彩` 页，首版只有 `双色球` 玩法。原有双色球逻辑保持不变：

- 点击 `生成推荐` 从轻服务端生成单式和复式推荐。
- 可调整复式红球数、蓝球数、近期窗口、预算注数和模型版本。
- 页面展示历史开奖、号码走势、逐球说明、模型对比和模型历史验证。
- 真实推荐结算只统计实际复式方案，奖金按固定奖级估算，一二等奖浮动奖金暂不计入。

双色球 CSV 格式：

```csv
issue,date,r1,r2,r3,r4,r5,r6,blue
2024001,2024-01-02,1,6,12,18,24,30,8
```

## 3. 体彩：足球彩票

进入 `体彩` 页，首版只有 `足球彩票` 子玩法，面向 2026 世界杯赛事：

- `刷新赛事`：从轻服务端获取足球赛事；服务端会优先尝试官方竞彩接口，失败时使用缓存或内置世界杯赛程。
- `生成推荐`：从轻服务端获取实验性推荐。
- 支持玩法展示：胜平负、让球胜平负、比分、总进球、半全场。
- 推荐只基于赛程、赔率字段和球队强弱标签做实验分析，不包含串关奖金计算，不保证结果。

## 4. 数据

进入 `数据` 页：

- 填写轻服务端地址，例如 `http://192.168.1.8:8000`。
- `双色球数据`：支持导入 CSV、服务端更新、官网直连。
- `体彩足球数据`：支持服务端更新，或导入服务端格式 JSON。
- `备份与恢复`：导出/恢复当前彩票数据。旧版本备份里的股票字段会被忽略。

## 5. 注意

- 双色球和足球推荐都是统计实验和娱乐工具，不保证中奖。
- 体彩足球首版不做投注单、串关、倍数、理论奖金或赛果结算。
- 官方竞彩站点可能拦截服务端抓取；这是预期场景，服务端会自动降级到缓存或内置数据。
