# WealthLab 当前审查

## 已完成

- 原生安卓 App：Kotlin、Compose、Room。
- 双色球：CSV导入、官网直连、轻服务端更新、历史开奖展示、目标期号展示。
- 双色球推荐：服务端即时生成，默认 3 组单式 + 1 组红蓝复式、自定义复式方案、预算建议、30期样本门槛、稳定生成、逐组解释、逐球解释和全量号码榜单。
- A股：CSV导入、HTTP更新、股票观察池、四类策略、回测结果展示。
- 本地数据：Room 存储、JSON 备份与恢复。
- 轻服务端：FastAPI 抓取并缓存双色球历史开奖，同时负责分析和推荐生成。

## 仍然偏初版的地方

- 双色球模型已升级到“全量频率 + 最近窗口加权 + 遗漏 + 形态约束”的统计评分，并增加历史回测、模型对比和推荐表现追踪，但仍不是严肃预测模型，也不会提高理论中奖概率。
- A股稳定数据源仍需要后续接 AKShare/Tushare。
- A股图表较轻量，只显示资金曲线，没有 K线图、指标叠加和交易点标记。
- 回测模型是日线收盘价撮合，暂不支持复权、分红、交易日历、涨跌停和停牌。

## 建议下一步

1. 给轻服务端增加定时刷新、部署脚本和模型版本记录。
2. 增加双色球胆拖玩法、预算金额换算和更细的模型参数保存。
3. 增加股票策略参数页，让 MA周期、RSI阈值、手续费、滑点可编辑。
4. 增加 K线图、指标叠加和买卖点标记。
5. 增加数据质量检查：重复日期、缺失交易日、异常价格、开奖格式错误。
