# WealthLab Review

## 当前范围

- 福彩：双色球数据更新、推荐生成、模型历史验证、模型对比、号码榜单和真实推荐结算。
- 体彩：足球彩票首版，覆盖世界杯赛事展示和五类竞彩足球玩法的实验性推荐。
- 轻服务端：负责双色球抓取/推荐、体彩足球官方优先抓取、缓存和内置世界杯赛程兜底。
- Android：底部导航为：首页、福彩、体彩、数据。

## 已移除

- A股日线导入、股票观察池、量化策略、交易信号和回测。
- 后端股票日线接口与 `akshare` 依赖。
- Room 股票/量化实体，数据库 7 -> 8 迁移会丢弃旧股票表。

## 风险与边界

- 彩票推荐不提升理论中奖概率，只适合自用实验和复盘。
- 体彩官方接口可能被安全策略拦截，第一版必须允许缓存或 JSON 导入兜底。
- 足球首版不做投注单、串关奖金、赛果结算或购彩能力。

## 后续建议

1. 增加足球赛事结果导入和推荐复盘。
2. 增加传统足彩玩法，如胜负彩、任选九、进球彩、半全场。
3. 为福彩新增 3D、七乐彩等子玩法。
