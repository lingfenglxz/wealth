WealthLab 重新设计预览 v2

现代金融科技风格 · 全面布局优化 · 信息架构重构 · 单文件拆分。本次重点优化卡片布局、按钮规范、冗余移除。

布局与信息架构优化清单

v2 新增
移除
首页 StatusCard 状态提示卡
移除首页顶部的"状态"横幅卡片。该信息属于系统反馈，不应占据首页黄金位置。改为：成功时静默，仅在 TopAppBar 小图标显示连接状态；有重要消息时用顶部 Toast/Snackbar 临时提示。
移除
福彩页 WelfareLotteryPage 的单按钮 ChoiceButton 行
第 304-306 行：只有一个"双色球"ChoiceButton 且 onClick 为空操作，纯装饰。直接移除整个 Row 和 game 状态，LotteryPage 直接渲染。
移除
体彩页 SportsLotteryPage 的单按钮 ChoiceButton 行
第 342-345 行：只有一个"足球彩票"ChoiceButton，selected=true 且 onClick={} 无操作。移除。
移除
CardRow 死代码
第 1245-1263 行：CardRow composable 定义后从未被调用。移除。
重构
福彩页卡片过多(11个)，信息过载
当前 LotteryPage 一屏内堆叠 11 个卡片（ActionHeader/分析/结算/走势/参数/组合/回测/对比/榜单/推荐/历史）。重组为 3 个分组：「推荐与生成」→「数据分析」→「历史记录」。用 sticky 分组标题分隔，支持快速跳转。
重构
首页布局重新排序
原顺序：状态卡→结算→推荐→足球。新顺序：ROI Hero(结算)→推荐→足球→快捷入口。移除状态卡，ROI 提升为 Hero 卡片视觉焦点。
重构
体彩页嵌套展开 → 扁平化
FootballRecommendationInline 在已展开的 FootballMatchCard 内再展开，三层嵌套。改为：赛事卡直接显示赔率三栏+推荐摘要，点击赛事进入详情视图（或底部 Sheet），消除嵌套。
重构
数据页布局合并
"双色球数据"和"体彩足球数据"两个卡片结构几乎相同。合并为单个"数据同步"卡片，内部分两个 section。减少重复，信息更紧凑。
按钮
按钮尺寸无规范，统一为 3 级
当前按钮高度混乱（36dp Button 默认、无统一 padding）。规范：btn-lg(52dp,全宽主操作)、btn-md(44dp,常规)、btn-sm(36dp,辅助)。主 CTA 用 lg，次要用 md/sm。
按钮
"展开/收起"按钮样式冗余
每个卡片都用 OutlinedButton 做"展开/收起"，视觉噪音大。改为：卡片标题右侧用图标箭头(▾)作为展开指示器，整行可点击，无需独立按钮。
按钮
CountStepper 的 +/- 用 Text 字符
第 682-684 行：用 Text("-")/Text("+") 作按钮内容，无图标、无无障碍标签。改为 Material Icons(Remove/Add) + contentDescription。
按钮
数据页按钮全用水平 Row 包裹
第 721、736、749 行：单按钮也用 Row+horizontalScroll 包裹，多余。直接渲染按钮即可。更新按钮改为全宽 btn-lg。
架构
MainActivity.kt 1393 行单文件拆分
37 个 composable 全挤在一个文件。拆分为：ui/theme/(7个令牌文件) + ui/components/(11个组件文件) + ui/screens/(4个页面文件) + MainActivity.kt(仅~80行入口)。每个文件单一职责。
交互
静默截断列表
.take(20/30/40) 截断无提示。改为：默认显示 N 条 + 底部"查看全部 X 条"按钮或"加载更多"。
交互
无加载/错误状态
网络请求无 spinner、无禁用态、失败仅改字符串。按钮加载时禁用+spinner，失败显示错误卡+重试按钮。
交互
展开状态用 remember，LazyColumn 回收后丢失
卡片展开状态用 remember { mutableStateOf }，列表项被回收后状态重置。改为 rememberSaveable 或提升到 ViewModel。
